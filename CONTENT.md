# Контент — что заменить владельцу

Весь сайт — один файл `index.html`. Найдите нужное место (Ctrl+F по подсказке
из колонки «Где»), замените, затем `git add . && git commit -m "content" && git push`.
Сайт обновится за ~30 сек.

Все плейсхолдеры на сайте видно сразу — они подсвечены пунктирной рамкой
(`____`, `[уточнить…]`, «см. CONTENT.md»). Пока не заменены — гость видит, что
данные временные, ложной информации на сайте нет.

## 1. Яндекс.Метрика (аналитика) — приоритет высокий

| Где | Сейчас | Поставить |
|-----|--------|-----------|
| `var METRIKA_ID=0;` (в `<script>`) | `0` (Метрика выключена) | номер счётчика, напр. `var METRIKA_ID=12345678;` |

Как только поставите реальный номер — автоматически включатся Вебвизор,
тепловые карты и все цели (`booking_widget_click`, `whatsapp_click`,
`telegram_click`, `phone_click`, `faq_reached`, `houses_reached`). Цели в коде
уже привязаны, отдельно настраивать в HTML ничего не нужно.

## 2. Виджет бронирования bronirui-online.ru — приоритет высокий

| Где | Сейчас | Поставить |
|-----|--------|-----------|
| блок `<div class="widget-box" id="bookingWidget">` | заглушка с текстом | вставить код встраивания (iframe), который выдаёт личный кабинет bronirui-online.ru |

Замените всё содержимое `<div id="bookingWidget">…</div>` на iframe от
bronirui-online.ru. API и оплата работают на их стороне — менять ничего
больше не нужно (это вне scope, см. спек §10).

## 4. Цены и правила домиков

| Где (Ctrl+F) | Поставить |
|--------------|-----------|
| `от ____ ₽ будни · ____ ₽ выходные` (Синий и Зелёный) | реальные цены буднего/выходного дня |
| `Заезд с __:__, выезд до __:__` | время заезда и выезда |
| `условия уточняются` (питомцы / доп. гости) | реальные правила |
| Купель/Чан: `уточняется — см. CONTENT.md` | цена и длительность сеанса |
| Баня: `Цена: уточняется` | цена бани и как записаться |

Список «Что внутри» (кровать, кухня, санузел, отопление, Wi-Fi) уже заполнен
по спецификации — проверьте, что всё совпадает с реальностью, поправьте при
необходимости.

## 5. Отзывы (раздел «Что говорят гости»)

В `<script>` массив `var reviews=[]` сейчас генерирует 6 плейсхолдеров.
Замените на реальные тексты:

```javascript
var reviews=[
  {text:"Реальный текст отзыва.", who:"Анна · март 2026"},
  {text:"Ещё один отзыв.",        who:"Игорь · февраль 2026"}
  // … 5–8 штук, спек §4.7
];
```

Тексты, не скриншоты. Минимум 5, лучше 6–8.

## 6. FAQ (ответы с пометкой «уточнить»)

В `<script>` массив `var FAQ=[]`. Часть ответов уже по фактам из спека.
Замените всё, где в ответе стоит `[Уточнить…]` / `[уточнить…]`:

- Можно с животными?
- Есть ли мангал и дрова? (наличие/цена дров)
- Как работает купель? (длительность/цена)
- Можно ли приехать на одну ночь? (минимальный срок)
- Как добраться без машины? (электричка/такси)

Можно добавлять/удалять вопросы — просто правьте элементы массива `FAQ`.

## 7. Карта (раздел «Как добраться»)

| Где (Ctrl+F) | Поставить |
|--------------|-----------|
| `yandex.ru/map-widget/v1/?ll=36.60%2C55.20&z=10` | точные координаты: на Яндекс.Картах найдите точку → «Поделиться» → «Код для сайта» → подставьте `ll=ДОЛГОТА,ШИРОТА` и нужный `z` |

Сейчас карта показывает приблизительный район (подписано плейсхолдером).

регистратора домена добавить DNS-записи на GitHub Pages:

- A-записи `@` → `185.199.108.153`, `185.199.109.153`,
  `185.199.110.153`, `185.199.111.153`
- CNAME `www` → `mihalgennadich.github.io`

До этого сайт доступен по адресу GitHub Pages (см. README / сообщение от
исполнителя).
