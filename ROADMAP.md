# Papino Village — что дальше (дорожная карта)

Файл, чтобы вернуться и ничего не потерять. Технически сайт готов и
задеплоен; ниже — что осталось сделать владельцу и в каком порядке.
Детали по плейсхолдерам — в `CONTENT.md`, по фото — в `PHOTOS.md`.

## Где мы сейчас

- Новый сайт: мультистраничник, статический, на GitHub Pages.
  Live: https://mihalgennadich.github.io/papinovillage/
- Страницы: `/`, `/domiki/`, `/banya-chan/`, `/kak-dobratsya/`,
  `/otzyvy/`, `/policy.html`.
- Основной сайт пока на Тильде (papinovillage.ru) — он в проде, домены
  ведут на него. Новый сайт его НЕ затрагивает.
- Вывод по сравнению: **прямо сейчас Тильда лучше** (реальные фото, на
  домене, в поиске). **После фото + перевода домена — новый сильнее**
  (скорость, SEO-разметка, мультистраничность, OG под VK, бесплатный
  хостинг). Решают не «движок», а два шага ниже (P0). Тильду не выключать,
  пока новый не готов на 100% и не на домене.

## P0 — без этого новый сайт «спит»

- [ ] **Реальные фото.** Положить `.jpg` с теми же именами в `images/...`
      (инструкция — `PHOTOS.md`). Особенно `images/hero/summer.jpg` — оно же
      og:image для VK/Telegram, нужно ≥1200×630. Без фото эмоция (=брони)
      теряется.
- [ ] **Перевод домена на новый сайт (цутовер).** Пока не сделано — новый
      сайт в поиске не участвует, canonical у всех страниц уже ведёт на
      papinovillage.ru намеренно.
  1. У регистратора домена DNS на GitHub Pages:
     - A `@` → `185.199.108.153`, `185.199.109.153`,
       `185.199.110.153`, `185.199.111.153`
     - CNAME `www` → `mihalgennadich.github.io`
  2. Вернуть в репозиторий файл `CNAME` со строкой `papinovillage.ru`.
  3. В настройках репозитория GitHub → Pages указать домен, дождаться
     галочки HTTPS.
  - Делать, когда фото готовы. Старый сайт и домены до этого не трогаются.

## P1 — включить «зрение» и аналитику

- [ ] **Яндекс.Вебмастер** (бесплатный кабинет владельца сайта, аналог
      Google Search Console). Зачем: подтвердить сайт, отдать
      `sitemap.xml`, видеть индексацию/ошибки, кнопка «переобход», задать
      **регион** (Калужская обл. / Москва — важно для аренды).
  1. webmaster.yandex.ru → добавить сайт papinovillage.ru.
  2. Подтвердить мета-тегом: код вставить в
     `<meta name="yandex-verification" content="">` в `index.html`.
  3. Добавить sitemap: `https://papinovillage.ru/sitemap.xml`.
  4. Указать регион в разделе «Региональность».
- [ ] **Google Search Console** — то же для Google: добавить сайт, код в
      `<meta name="google-site-verification" content="">`, отдать sitemap.
- [ ] **Подставить owner-only** (всё перечислено в `CONTENT.md`): номер
      счётчика Яндекс.Метрики, iframe-код bronirui-online.ru, ссылки
      WhatsApp/Telegram, точные координаты карты.

## P2 — рост и доверие (часто важнее классического SEO для аренды)

- [ ] **Яндекс.Бизнес / карточка в Яндекс.Картах.** Для посуточной аренды
      это нередко приносит больше, чем SEO сайта. Даёт: карточку в Картах и
      поиске, рейтинг и отзывы, виджет отзывов для вставки на сайт, телефон
      и маршрут. Завести на yandex.ru/business, заполнить, добавить фото.
- [ ] **Отзывы с Яндекса — три пути:**
  - Официальный виджет Яндекс.Бизнеса (iframe): реальные свежие отзывы и
    звёзды на сайте. Минус — почти не стилизуется и в индекс сайта не идёт
    (контент на домене Яндекса). Для людей, не для SEO.
  - Парсить Яндекс и публиковать у себя — нарушает правила, рискованно,
    ломко. Не делать.
  - Ручной перенос текстов статическим HTML (как сейчас 6 отзывов на
    `/otzyvy/`). Без имён или с разрешения автора (персональные данные).
  - Когда на Яндекс.Картах накопится реальная средняя оценка — впишем
    честный `aggregateRating` в Schema-разметку → звёзды в выдаче.
    **Значение должно быть настоящим, не выдуманным.**
- [ ] **Агрегаторы посуточной аренды.** Высокочастотные запросы в поиске
      держат именно они. Присутствие важнее, чем «качать» эти запросы
      сайтом: Суточно.ру, Авито, Островок, Яндекс Путешествия, 2ГИС.
- [ ] **Проверить редиректы доменов.** `usadba-papino.ru`,
      `usadbapapino.ru` → 301 на papinovillage.ru (ОК).
      `papino-village.ru` по HTTPS не ответил при проверке — проверить.
      `.рф`-домены (усадьба-папино.рф, усадьбапапино.рф) — проверить в
      Яндекс.Вебмастере, что тоже 301 на основной.

## Честно про потолок SEO

SEO в посуточной аренде — медленная игра. Высокочастотку
(«глэмпинг подмосковье») держат агрегаторы и Яндекс.Карты, не сайт одного
объекта. Реалистичная роль сайта: бренд-запросы, длинный хвост и гео,
конверсия трафика из VK / агрегаторов / рекламы. Сайт теперь технически
чистый и «понятный» поиску — это нужная база, но сама по себе она брони не
наливает. Самый окупаемый следующий шаг — Яндекс.Бизнес + агрегаторы (P2).

## Где что править

- Тексты страницы — в соответствующем `*/index.html`.
- Общий вид — `assets/styles.css`. Общая логика — `assets/site.js`.
- Плейсхолдеры и owner-only — `CONTENT.md`. Фото — `PHOTOS.md`.
- После любой правки: `git add . && git commit -m "..." && git push` →
  сайт обновится за ~30 сек.
