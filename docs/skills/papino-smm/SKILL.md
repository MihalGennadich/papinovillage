# Papino Village SMM

## Overview

Пишет и разбирает SMM-контент для глэмпинга Papino Village (2 А-фрейм домика,
65 км от Москвы). Принцип: каждый текст — на доказательных приёмах ниши, на
подтверждённых фактах объекта и проходит критерии качества перед выдачей.
Выдумывать факты и упоминать Яну — запрещено.

## When to use

- Запрос написать/предложить пост, Stories, Клип, Telegram-пост для Papino Village
- Сгенерить контент-план на период (неделя/месяц)
- Разобрать существующий пост и переписать его
- Оценить статистику группы и дать рекомендации

**NOT for:** другие объекты/бизнесы (скилл заточен только под Papino Village);
генерация самих фото/видео (скилл даёт визуал-бриф, не медиа); автопостинг.

## Hard rules (нарушение = брак, переписать)

1. **Яна — нигде и никак.** Бывшая совладелица, не в проекте. Имена реальных
   гостей — только если имя публично в отзывах на Яндекс-Картах, иначе обезличить.
   Приватные/семейные детали владельца — не в публичный контент.
2. **Только подтверждённые факты** из `references/papino-profile.md`. Нет факта →
   пометка «нужно уточнить у владельца», не выдумка.
3. Голос — **Михаил/«мы»**, тёплый, прозрачный; без канцелярита и инфоцыганщины.
4. Перед выдачей — самопроверка по `references/post-criteria.md` (Слой 1 +
   оверлей посыла + стоп-лист).

## Workflow — 4 режима

Сначала определи режим. Если вход неоднозначен — уточни у пользователя.

### Режим 1 — Одиночный пост/Stories/Клип
1. Зафиксируй: формат (VK пост / Stories / Клип / Telegram), посыл (тип из
   `references/content-pillars.md`), повод/тему.
2. Доспроси недостающие факты (сверь с GAP-листом профиля) — не выдумывай.
3. Подбери механику/хук из `references/marketing-playbook.md`.
4. Напиши черновик по `references/format-rules.md` для этого формата.
5. Самопроверка по `references/post-criteria.md`. Не прошло — переписать.
6. Выдай: **текст** + **визуал-бриф** + **альтернативный хук** + 1 строка
   «почему сработает» (со ссылкой на приём).

### Режим 2 — Контент-план на период
1. Уточни: период, количество постов, микс форматов.
2. Разложи по столпам и посылам (`content-pillars.md`) и поводам (сезон/события);
   соблюдай микс ленты 60/30/10 и каденс из `format-rules.md` — в плане ОБЯЗАТЕЛЬНО
   заложить долю VK Клипов (приоритетный формат органики, ориентир 3–5/нед) и
   регулярные Stories, не только текстовые посты.
3. Сгенерь N постов (каждый — как Режим 1, кратко).
4. Собери в файл `C:\Users\kulle\IdeaProjects\papinovillage\docs\smm\YYYY-MM-DD-content-plan.md`.
   Формат и статусы — как в существующем v4 плане: `ГОТОВ / НУЖНО ФОТО /
   НУЖНА СЪЁМКА / НУЖНО UGC / ШАБЛОН`. Файл — артефакт вне скилла; ведёт владелец.

### Режим 3 — Разбор существующего поста
1. Вход: текст или URL поста.
2. Прогони по `references/post-criteria.md`, отметь пройдено/нет по пунктам.
3. Поставь диагноз слабого ER (хук / одна мысль / посыл / CTA / тон / факты).
4. Выдай переписанную версию, которая проходит критерии.

### Режим 4 — Оценка статистики
1. Вход: метрики по постам/рубрикам (охват, реакции, ER), желательно за период.
2. Интерпретируй с учётом волнового охвата (оценка на день 5+) и сигналов
   успеха по посылам (`content-pillars.md` F2).
3. Выдай: что усиливать, какие посылы/форматы работают, рекомендации по каденсу
   и миксу. Сравнивай показатели с **собственной историей аккаунта** (относительно:
   этот посыл vs другой, динамика), НЕ вводи абсолютные пороги «N сохранений = ок» —
   их нет в данных; сигналы успеха — направленные гипотезы, калибруемые фактом.

## Self-check (Слой 1 — каждый выход)

Хук в 1-й строке/3 с · одна мысль · тон Михаил/«мы» · только факты профиля ·
**нет Яны**, гости обезличены/с разрешения · CTA под цель · формат-комплаенс ·
визуал-бриф приложен · не репост чужого · прошёл стоп-лист. Слой 2 (оверлей
посыла) и полный стоп-лист — `references/post-criteria.md`.
