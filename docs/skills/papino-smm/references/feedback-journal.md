владельца) · `в-критерии` (применено через Режим 5, указать файл и коммит) ·
`отклонено` (не подтвердилось).

## Правило применения

1. Накопить ≥2–3 согласованных наблюдения по одному паттерну (один пост — не тренд;
   помнить про волновой охват: мерить на день 5+).
2. Сверить с доказательной базой `docs/smm/smm-research-*.md` — не противоречит ли.
3. Только тогда — предложить правку в Режиме 6 → применить Режимом 5 с ре-валидацией.
4. Перевести запись в статус `в-критерии` с указанием файла и коммита.
