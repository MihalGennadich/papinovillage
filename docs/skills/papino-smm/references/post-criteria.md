# Критерии качества поста

> Двухслойная модель. Слой 1 — каждый пост. Слой 2 — оверлей под посыл (имена 1:1
> с `content-pillars.md`). Скилл прогоняет это перед выдачей любого текста.
> Источник критериев — ресерч 2026-05-17 (F2/F3), не «из головы».

## Слой 1 — универсальная база (любой пост, любой посыл)

- [ ] Хук в первой строке (текст) / первые 3 с (клип) — цепляет за ~1,5 с
- [ ] Одна мысль на пост (не каша)
- [ ] Тон: Михаил/«мы», тёплый, прозрачный; без канцелярита и инфоцыганщины
- [ ] Только подтверждённые профилем факты; пробел → пометка «нужно уточнить», не выдумка
- [ ] **Яна НЕ упомянута**; имена гостей — с разрешения или обезличены — БЛОКЕР
- [ ] CTA под цель поста (бронь / сохранение / коммент / репост / дочитать)
- [ ] Формат-комплаенс канала (длина/структура — см. `format-rules.md`)
- [ ] Для VK-поста: встроен опрос ИЛИ явно обосновано, почему его нет
- [ ] Приложен визуал-бриф (что на фото/видео/обложке и почему)
- [ ] Не репост чужого; AI-черновик персонализирован, с реальными медиа
- [ ] Прошёл стоп-лист (ниже)

## Слой 2 — оверлей по посылу (критерий «сработал» = сигнал успеха)

- **Атмосферно-эмоциональный** — есть сенсорика/сцена, вызывает желание; заточен
  под сохранение/репост.
- **UGC / история гостя** — реальная история/фраза гостя; обезличено или с
  разрешения; провоцирует репост/коммент.
- **Сезонный / событийный** — привязан к поводу/сезону; для несезона — собственный
  нарратив, не «лето минус тепло»; ведёт к броне.
- **Информационный / FAQ** — отвечает на реальный вопрос; сканируемо; формат «на
  сохранить».
- **Закулисье / голос Михаила** — личный голос, конкретные детали; даёт повод для
  комментария.
- **Вовлекающий / опрос** — есть встроенный опрос/вопрос с явным триггером клика.
- **Продающий / оффер** — конкретный оффер и причина сейчас, без давления; ≤10%
  ленты; явный путь в бронирование — обязательна ссылка (papinovillage.ru/виджет),
  телефон ИЛИ точная инструкция «как забронировать», не расплывчатое «напишите нам».

## Стоп-лист (мгновенный блок — пост не выдавать)

1. **Любое упоминание/намёк на Яну** (бывшая совладелица — нигде)
2. Имя реального гостя без подтверждённого разрешения
3. Выдуманный факт об объекте (нет в профиле → пометка, не сочинять); **«кошка»
   не подтверждена — не использовать**
4. Репост/пересказ чужого контента как своего
5. Давление-клише: «успей», «осталось N мест», «🔥АКЦИЯ🔥», канцелярит
6. Несколько мыслей в одном посте
7. AI-вода без персонализации и реальных медиа

## Самопроверка

Прогнать Слой 1 (все пункты) + оверлей нужного посыла + стоп-лист. Любой
невыполненный пункт Слоя 1 или сработавший стоп-лист → переписать, не выдавать.
