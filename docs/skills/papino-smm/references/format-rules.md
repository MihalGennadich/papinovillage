# Форматные правила (из ресерча 2026-05-17 секции D / F5)

> Числа — из исследований RU 2024–2026. Где число не из источника — помечено
> «практика», не выдавать за измеренное.

## VK пост (лента)

**Правила:**
- Хук в первой строке — цепляет до сворачивания текста (~1,5 с внимания).
- Одна мысль на пост; структура: хук → развитие → один CTA.
- По возможности встроить **опрос** (рычаг ре-инклюда в ленту).
- Фото/карусель — реальные, не сток; для AI-черновика обязательны живые медиа.
- CTA на сохранение/коммент/репост (не только «бронируйте»).
- Длина (практика, не измерено в ресерче): ориентир ~500–1500 символов; ключевая
  мысль и хук — ДО сворачивания текста VK («ещё»). Длиннее — только лонгрид-история
  с сильным первым абзацем.
- Без репостов чужого контента. Время: вс 20:00 или чт–пт вечер.

**Чек перед публикацией:** [ ] хук в 1-й строке [ ] 1 мысль [ ] CTA под цель
[ ] есть опрос ИЛИ обоснованно нет [ ] реальные медиа [ ] тон Михаила/«мы»
[ ] нет Яны/чужого репоста.

## VK Stories

**Правила:**
- **≤7 кадров** (резкий провал досмотра после 4-го; 1–7 — оптимум).
- Кадр-видео **≤15 с**; формат **9:16, 1080×1920**.
- Safe-zone: ключевой текст НЕ в верхних 10% и нижних 20% кадра; отступ ≥200 px.
- **Обязателен интерактив-стикер** (опрос/вопрос/тест) — +25% просмотров.
- 1–2 хэштега (+~15% охвата). Первый кадр — хук (вопрос/интрига), иначе свайп.

**Чек:** [ ] ≤7 кадров [ ] хук в 1-м кадре [ ] интерактив-стикер есть
[ ] текст в safe-zone [ ] тон/Яна-блокер.

## VK Клип (приоритетный формат органики)

**Правила:**
- Длина **15–60 с** (до 60 с +70% просмотров; <5 с не продвигается).
- **Хук в первые 3 с** (окно удержания ~8 с); цель досмотр **>80%**.
- **9:16**, 60 fps; safe-zone верх 10% / низ 20%.
- Обложка: ключевая фраза/оффер + лицо человека (повышает CTR).
- **3–5 хэштегов**; музыка **только из каталога VK** (условие рекомендаций).
- CTA: сохрани/подпишись/перешли. Каденс спринта **3–5 клипов/нед**.
- Сценарий: первый кадр без «разгона»; идея одна; держать темп до конца.

**Чек:** [ ] 15–60 с [ ] хук в 3 с [ ] обложка оффер+лицо [ ] музыка из каталога
VK [ ] 3–5 хэштегов [ ] CTA [ ] тон/Яна-блокер.

## Telegram-канал (нет алгоритма: охват = подписчики + пересылки)

**Правила:**
- Одна идея на пост. Длина: анонс **<500 симв.**, стандарт **≤~1000**, лонгрид
  1000+ (лимит платформы 4096 / 1024 с медиа).
- **Жирный** — заголовок/подзаголовки; эмодзи — умеренно, как маркеры рубрик.
- CTA в конце, простым глаголом («Бронируйте», «Пишите») + «перешлите/сохраните»
  (единственный виральный механизм здесь — форварды).
- Постинг утром **5:00–11:00**; буфер ≥1 ч между постами (иначе −30% кликов).
- Микс канала: ~40% польза / 20% развлечение / 40% продажа (отличается от VK).

**Чек:** [ ] 1 идея [ ] длина под тип [ ] заголовок жирным [ ] CTA-глагол + триггер
форварда [ ] тон/Яна-блокер.

## Общий принцип каденса

2–3 фид-поста VK/нед + 3–5 Клипов/нед + регулярные Stories. Микс ленты VK ≈
60% жизнь-внутри-заезда / 30% инфраструктура-реальность / 10% оффер. Эффект мерить
на день 5+ (волновой охват).
