# Пример: VK Клип (посыл «Атмосферно-эмоциональный»)

## До (слабый вариант)

30-секундный ролик: 5 с заставки с логотипом, медленная панорама участка,
музыка не из каталога VK, текст «Добро пожаловать в Papino Village».
Хука нет, «разгон» убивает досмотр, музыка блокирует рекомендации.

## После (по критериям) — ~25 с

- **ХУК (0–3 с):** треск дров крупным планом, огонь печи-камина. Без заставки.
  Голос/титр: «−15 за окном. +24 у печки.»
- **Удержание (3–8 с):** игла опускается на пластинку, тёплый свет, треугольное окно
  в снегу за стеклом.
- **Тело (8–22 с):** чашка чая на подоконнике, плед, кадр чана с паром под звёздами.
- **Финал/CTA (22–25 с):** титр «Зелёный домик, Papino Village» → «Сохрани, чтобы
  не потерять».

—
Текст на обложку: «−15 снаружи / +24 у печки»
Лицо на обложке: нет (атмосфера сильнее лица в этом посыле)
Музыка: спокойная инструментальная из каталога VK
Хэштеги: #глэмпинг #papinovillage #зимнийотдых #ап198 #подмосковье
Визуал-бриф: реальные зимние кадры Зелёного и чана; темп ровный, без резких склеек.
Посыл: Атмосферно-эмоциональный · Почему сработает: сенсорный хук в 3 с +
контраст «мороз/тепло» → высокий досмотр и сохранения (сигнал успеха посыла).
Статус: НУЖНА СЪЁМКА

## Разбор

- **Хук в 3 с** без «разгона» — критично для попадания в рекомендации (97% просмотров).
- **15–60 с** (здесь 25), музыка **из каталога VK** — условие рекомендаций.
- **Один посыл** — атмосфера, без перечисления услуг.
- **CTA на сохранение** — целевой сигнал атмосферного посыла.
- **Факты** — печь-камин и чан из профиля (Зелёный). Без Яны.
