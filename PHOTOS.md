# Фотографии

Замена: положите свой `.jpg` с **точно таким же именем** в ту же папку → `git add . && git commit && git push` → сайт обновится за ~30 сек.

| Файл | Что на фото | Размер (рек.) | Обязательно |
|------|-------------|---------------|-------------|
| `images/hero/summer.jpg` | Главный экран, лето | 1920×1080 | **Да** |
| `images/hero/winter.jpg` | Главный экран, зима | 1920×1080 | Нет (fallback на summer) |
| `images/hero/spring.jpg` | Главный экран, весна | 1920×1080 | Нет (fallback на summer) |
| `images/hero/autumn.jpg` | Главный экран, осень | 1920×1080 | Нет (fallback на summer) |
| `images/blue-house/1..3.jpg` | Синий домик | 1200×800 | **Да (мин. 3)** |
| `images/green-house/1..3.jpg` | Зелёный домик | 1200×800 | **Да (мин. 3)** |
| `images/gallery/1..12.jpg` | Атмосфера: купель, огонь, еда, природа | 1000×1000 | Желательно |
| `images/sauna/1..2.jpg` | Баня | 1200×800 | Желательно |

Можно добавлять больше фото домиков (`4.jpg`, `5.jpg` …) — слайдер подхватит автоматически до 8 на домик.
