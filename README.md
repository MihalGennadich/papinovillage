# Papino Village

Статический сайт глэмпинга Papino Village. Один файл `index.html` + папка `images/`.
Хостинг: GitHub Pages. Деплой: push в `main` → сайт обновляется за ~30 сек.

## Замена фото
См. `PHOTOS.md` — таблица файлов, размеров и куда класть.

## Замена текста (цены, телефоны, отзывы, FAQ, счётчик Метрики, виджет брони)
См. `CONTENT.md` — каждый плейсхолдер помечен и описан.

## Локальный просмотр
`python -m http.server 8080` → http://localhost:8080
